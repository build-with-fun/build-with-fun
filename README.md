## 🧭 How a Project Flows

Every project starts as a plan, not a prompt:

```mermaid
flowchart LR
    A["💡 Idea"] --> B["🧭 Scope<br/>goals · limits · plan"]
    B --> C["🎨 Design<br/>UX flows · architecture"]
    C --> D["🏗️ Build<br/>full-stack · small milestones"]
    D --> E["🤖 AI Layer<br/>agents · tools · memory"]
    E --> F["🚀 Ship<br/>deploy · measure · iterate"]
    F -. feedback .-> B

    classDef default fill:#0B1F3A,stroke:#0EA5E9,stroke-width:1.5px,color:#ffffff
    classDef ship fill:#F5A623,stroke:#F5A623,stroke-width:1.5px,color:#0B1F3A
    class F ship
```

## 🤝 Working With Me

| | |
|:---|:---|
| 📝 **Scope before code** | A written plan up front: what we're building, what we're not, and how we'll know it works. |
| 🔍 **No black boxes** | Architecture decisions explained in plain language, not buried in the code. |
| 🎯 **Small, demo-able steps** | Progress lands in milestones you can click through, not in one big reveal at the end. |
| 📦 **Clean handoff** | Readable code, clear documentation, and a project you can run without me. |
